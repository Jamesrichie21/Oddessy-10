# 🧠 Neural Football Predictor v5.8

## Deploy to Vercel
1. Push to GitHub
2. Import in Vercel
3. Add Environment Variables: FOOTBALL_DATA_API_KEY, API_FOOTBALL_KEY
4. Deploy

## Features
- 30 second gap between league fetches
- Shared localStorage across all users
- Refresh button to re-fetch all leagues
- Auto-predict with Elo, Poisson, Monte Carlo
